# 📄 Filebench – Browser-Based Image & PDF Toolkit

**Filebench** is a lightweight, browser-based utility that performs common **Image** and **PDF** operations entirely on the client side. All file processing happens locally in the user's browser, ensuring privacy, security, and fast performance without requiring any server uploads.

## Features

* 🖼️ **Image → PDF**

  * Convert one or more images into a single PDF document.
  * Supports JPG, PNG, and WEBP image formats.
  * Preserves image order during PDF generation.
  * Custom output filename.

* 📄 **PDF → Image**

  * Convert PDF pages into high-quality PNG images.
  * Single-page PDFs download as a PNG.
  * Multi-page PDFs are automatically packaged into a ZIP archive.

* 📚 **PDF Merge**

  * Merge multiple PDF documents into one.
  * Interactive page thumbnail preview.
  * Select or deselect individual pages before merging.
  * Preserve page order across multiple PDF files.
